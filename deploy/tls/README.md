# deploy/tls — HTTPS 리버스 프록시용 서버 인증서 (git 미추적)

이 디렉터리에 리버스 프록시가 쓸 서버 인증서와 개인키를 둔다. 파일 이름은 고정이다
(`deploy/nginx/autocert.conf`가 이 이름으로 읽는다).

| 파일 | 내용 | 권한 |
| --- | --- | --- |
| `server.crt` | 리프 인증서 + 중간 CA를 이 순서로 이어붙인 PEM | `644` |
| `server.key` | 개인키 PEM (**암호 없이** — 암호가 걸려 있으면 nginx가 기동 중 멈춘다) | `600` |

발급·반입·갱신 절차는 **docs/manual/TLS.md**를 따른다.

- 이 디렉터리의 `README.md`를 제외한 모든 파일은 `.gitignore` 대상이다. **개인키·서버 인증서를
  저장소에 커밋하지 않는다.**
- 개인키는 백업 매체에도 평문으로 두지 않는다. 유출이 의심되면 인증서를 폐기(revoke)하고
  재발급한다.
