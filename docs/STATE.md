3. 도메인·Linux 시험 대상·운영 키 공급이 준비되고 범위가 승인되면 실발급→배포→reload·롤백을 검증한다. 데모 주문 autocert-demo.example.com은 CA pending·awaiting_validation 단계이고 발급·교체는 미완료다. 데모 로그인 성공만으로 무료 발급·검증 생략을 추정하지 않는다.
4. 센서 중계는 시험망 B1→B2→D1 도달성과 각 장비→첫 중계기 포트를 준비한 뒤 운영 설치 절차로 검증한다. 일반 에이전트는 중계하지 않으며 중계 지점 상위 경로·방화벽은 관리자 설정이다.
5. E 자동 갱신·재배포, P1.5 분해안, 오프라인 라이선스, P2 멀티테넌시·SNI·Origin/Edge는 기존 보류를 유지한다. 선행 착수하지 않는다. 템플릿 개선 후보 11항목은 docs/learn/2026-09-07-template-improvements.md에 모여 있고 사용자 보류 상태다.
