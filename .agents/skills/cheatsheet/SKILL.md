# 프로젝트 명령 카드

먼저 `.codex/conventions/codex-runtime.md`를 읽는다.
공유 카드 자료는 `.claude/skills/cheatsheet/SKILL.md`에 있다. 해당 파일의 카드에서
사용자가 요청한 부분을 읽어 출력하며, 카드의 명령을 실행하지 않는다.
Claude 전용 슬래시 명령·환경변수·역할 설정은 Claude 표기임을 밝힌다.
이를 Codex의 실행 도구나 권한 규칙으로 적용하지 않는다.
Codex의 템플릿 갱신을 묻는 경우 `.agents/skills/template-update/SKILL.md`를 안내한다.
실제 실행 요청은 현재 사용자 승인 범위와 Codex 실행 계약에 따라 별도로 처리한다.
