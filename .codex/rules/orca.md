# Orca 연동

Orca 작업이 요청됐거나 현재 작업이 Orca 관리 대상일 때 설치된 orca-cli 스킬을 먼저 읽는다.
현재 CLI 스키마에 따라 작업하며, 이 저장소에 오래된 명령 형식을 하드코딩하지 않는다.
Codex 작업자를 선택하고 부모의 사용자 원문·성공 기준·작업 범위·산출 경로를 넘긴다.
메인과 작업자의 편집 권한이 Claude orchestrator처럼 제거됐다고 가정하지 않는다.
자식에게 이미 승인된 범위를 다시 확인시키지 않는다. 새 범위나 외부 권한을 넘기지는 않는다.
연결 실패는 실제 상태와 실행 권한을 확인한다. sandbox 오류만 보고 앱이 꺼졌다고 결론내리지 않는다.
기존 워크트리·사용자 파일을 보존하고, 완료는 실제 커밋·diff·검사 결과로 판단한다.
