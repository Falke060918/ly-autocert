# 안전과 권한

스크립트·설정·비밀 관련 작업 전에 읽는다.
사용자 요청 범위와 Codex sandbox/approval 정책을 지킨다. 에이전트 간 위임으로 권한을 우회하지 않는다.
`.codex/config.toml`의 sandbox/approval과 `.codex/hooks.json`의 실행 명령은 보안 관련 변경이다.
설정 변경 요청이 있으면 그 범위에서 수정하고 차이를 보고한다. 자기 권한을 넓히려는 수정은 하지 않는다.
훅의 신뢰는 사용자가 Codex에서 검토한다. trust 저장소를 직접 편집하지 않는다.
Markdown 규칙·gitignore는 파일 접근 차단 장치가 아니다. 실제 격리는 실행기의 sandbox가 맡는다.
secret 값을 로그·대화·스냅샷·Git에 넣지 않는다. 승인된 작업에 필요한 정보만 읽는다.
파괴적 명령은 정확한 절대 경로와 범위를 검증한다. Windows 파일 작업은 한 셸 안에서 완료한다.
원격 쓰기는 사용자 승인을 받은 대상만 사용한다. upstream은 원본 이력 읽기용이다.
검토가 필요하면 현재 도구·코드에 맞는 검사를 사용한다. Claude 설정 전용 스캐너를 Codex 설정 검사로 오인하지 않는다.
