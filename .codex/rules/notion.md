# Notion — 승인된 프로젝트 페이지만 쓰기

Notion 작업을 요청받았을 때 이 파일과 .codex/identity의 notion 값을 읽는다.
앱/MCP 도구의 실제 연결 상태를 확인한다. ~/.codex.json이나 Claude의 프로젝트별 MCP 저장 형식을 사용하지 않는다.
서버 설정이 필요하면 Codex 공식 MCP 문서를 확인한다. 개인 인증 정보는 저장소에 기록하지 않는다.

notion 값이 pending/없음이면 쓰기를 건너뛰고 알려 준다.
일반 초기화·handoff가 Notion 페이지 생성을 승인하지 않는다.
페이지 생성이 요청됐다면 사용자가 정한 부모 아래에 만들고 반환 ID를 이 프로젝트 identity에 기록한다.

승인된 동기화 범위는 프로젝트 페이지 하위의 STATE/LOG/SPECS 슬롯이다.
부모 페이지의 사용자가 배치한 본문·표·열은 보존한다.
STATE는 현재 상태, LOG는 커밋 기록, SPECS는 파일별 하위 페이지로 대응한다.
대상 슬롯은 부모의 실제 자식에서 확인하고 같은 제목의 다른 프로젝트 페이지를 검색으로 대신 고르지 않는다.
슬롯이 없거나 모호하면 그 항목을 건너뛰고 알린다.
쓰기 전에 현재 내용을 읽고, 쓴 뒤 다시 읽어 내용·레이아웃을 확인한다.
동시 편집 흔적을 자신의 이전 사본으로 덮어쓰지 않는다.
페이지 ID가 있어도 현재 요청/기존 승인에 포함되지 않은 외부 쓰기는 하지 않는다.
